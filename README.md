## 📌 About the Project

**MarketPulse AI (Kisaan Sahayak)** is an AI-powered agricultural market intelligence platform designed to help farmers make better and more data-driven decisions about where and when to sell their crops.

Farmers often face difficulties such as:

- Lack of timely mandi price information
- Difficulty comparing prices across different markets
- Uncertainty about future crop prices
- Dependence on intermediaries
- Limited access to data-driven market insights

MarketPulse AI addresses these challenges by bringing **market prices, historical trends, price forecasting, mandi discovery, AI recommendations, and direct buyer connections** into a single platform.

The platform analyzes historical mandi data and uses **XGBoost-based machine learning models** to forecast crop prices for the next **7 days**. Based on the forecast and market trends, the recommendation engine provides actionable suggestions such as:

> 🟢 **SELL NOW**

or

> 🟡 **WAIT**

The goal is to make agricultural market information easier to understand and more useful for farmers.

## 🤖 3. AI-Based Price Forecasting

MarketPulse AI uses **XGBoost machine learning models** to predict commodity prices for the upcoming 7 days.

```text

        ↓

        ↓

        ↓
7-Day Price Forecast
```

- Historical prices
- Lag prices
- Moving averages
- Price volatility
- Temperature

- Market-related features

# 🚧 Challenges Addressed

## 1. Market Data Availability

Agricultural data can come from multiple sources and may contain inconsistent mandi or commodity names.

- Timeouts
- Missing data

- Naming inconsistencies

## 4. Data Quality

Historical datasets may contain:

- Missing values
- Duplicate records
- Outliers
- Inconsistent formats

## 5. Model Deployment

Machine learning models need to be integrated with a production backend through APIs.
